# MetricFlow layer

Project: `project/`, generated by `semglot build --profile metricflow` (models, the semantic
YAML and a time spine). `dbt_project.yml` and `profiles.yml` are hand-written setup. The profile
attaches `data/tpch.duckdb` as catalog `tpch`, and dbt builds its views into `../mf.duckdb`.

```bash
cd layers/metricflow/project && export DBT_PROFILES_DIR=$PWD
uv run dbt run && uv run mf validate-configs
uv run mf query --metrics revenue --group-by metric_time__month
```

Versions: dbt-core 1.12.6, dbt-duckdb 1.11.1, MetricFlow 0.15.0.
