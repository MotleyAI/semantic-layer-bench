# Snowflake layer

`project/definition.md` holds the `CREATE SEMANTIC VIEW BENCH.TPCH.TPCH` DDL, generated by
`semglot build --profile snowflake` from `model_snowflake/` (the same model, with sources in
`SNOWFLAKE_SAMPLE_DATA.TPCH_SF1`). Not run yet: it needs a Snowflake account and a `BENCH.TPCH`
schema to create the view in.
